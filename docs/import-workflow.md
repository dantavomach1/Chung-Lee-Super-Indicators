# Import Workflow

1. Create a folder under `indicators/`.
2. Paste the untouched TradingView code into `original.pine`.
3. Copy the same code into `source.pine`.
4. Add a changelog entry.
5. Add basic notes.
6. Do not refactor during import.
7. Do cleanup or refactor work in a separate later pass.
8. Only create a `published/` compiled file after the user asks for one.
