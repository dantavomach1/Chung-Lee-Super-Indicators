# Codex Operating Guide

- Preserve `original.pine` as the untouched reference copy.
- Only edit `source.pine` unless specifically instructed otherwise.
- Never delete working logic without explicit instruction.
- Never silently change trading logic.
- Prefer full paste-ready Pine files over tiny fragments.
- Use Pine Script's latest supported syntax only when modernization is explicitly requested.
- Keep complicated logic commented in simple language.
- Maintain `changelog.md` after every meaningful edit.
- Maintain `notes.md` with plain-English behavior notes.
- Keep `published/` files synchronized only when the user asks for a publish-ready version.
- Do not add a `LICENSE` file unless explicitly requested.
- Do not expose private strategy logic in public docs.
