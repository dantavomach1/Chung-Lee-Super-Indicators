# Notes

## Purpose

Lower-pane momentum indicator that combines up to five Slow Stochastic modules, up to five RSI modules, and a TTM Squeeze module with confluence and dashboard visuals.

## Current Behavior

Calculates configurable Stochastic, RSI, and TTM Squeeze layers, supports global and module-level source/timeframe choices, optional real OHLC requests, presets, confluence signals, consensus highlighting, dashboard output, and optional last-value labels.

## Inputs

Includes global source/timeframe inputs, visual/grid controls, master toggles, five Stochastic module input groups, five RSI module input groups, TTM Squeeze settings, confluence settings, and dashboard settings.

## Visuals

Uses `overlay=false`, plots global levels, Stochastic K/D lines, RSI and signal lines, TTM baseline/histogram/dots, background highlights, signal labels, right-side labels, and a dashboard table.

## Alerts

No `alertcondition()` or `alert()` calls are present in the imported code.
